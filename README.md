# Corporate Employee Attrition Analysis

## Project Overview
This project focuses on analyzing corporate employee attrition and predicting employee tenure using Python and Machine Learning.

The objective is to explore employee data, identify important attrition patterns, and generate meaningful insights that can support business decision-making.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Machine Learning
- Jupyter Notebook

## Project Activities
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Employee Attrition Analysis
- Data Visualization
- Machine Learning and Tenure Prediction

## Project Repository
This repository contains the project notebook and related analysis files.
